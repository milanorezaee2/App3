# راهنمای خیلی ساده: چطور کاری کنیم اعلان روی گوشی بیاید 🔔

این راهنما بدون هیچ اصطلاح سختی نوشته شده. قدم به قدم جلو برو. هر قدم گفته
چه کاری بکنی و **چه چیزی باید ببینی**. اگر چیزی دیدی که با این نوشته فرق داشت،
همان‌جا بایست و برایم بنویس.

---

## اول از همه: ماجرا چیست؟

اپ ما **دو تکه** دارد:

1. **برنامه‌ای که روی گوشی نصب می‌شود** (فایل APK)
2. **سروری که در اینترنت است** (Supabase) — پیام‌ها اینجا نگه داشته می‌شوند

اعلان روی گوشی فقط وقتی می‌آید که **هر دو تکه درست باشند**.

مثل پستخانه است:

| چیز | در پستخانه یعنی چه؟ |
|---|---|
| فایل SQL | صندوق پست را می‌سازیم (جایی که نامه‌ها می‌مانند) |
| تابع `chat-push` | نامه‌رسان (نامه را به گوشی می‌برد) |
| Webhook | زنگی که به نامه‌رسان می‌گوید «نامه داری!» |
| `CHAT_WEBHOOK_SECRET` | کلید درِ انبار (فقط نامه‌رسان دارد) |
| اعلان روی گوشی | نامه‌ای که به دست مردم می‌رسد |

**خبر خوب:** تکهٔ گوشی (کد اپ) سالم است. من همین حالا ۴۵ بررسی خودکار را
اجرا کردم و همه قبول شدند. پس کاری که مانده، در **سرور** و **نصب روی گوشی** است.

---

## قدم ۱ — صندوق پست را بساز ⏱ ۵ دقیقه

1. برو به سایت Supabase و وارد پروژه‌ات شو (همان `doagwkssxtxseuavrxnr`).
2. از منوی چپ بزن **SQL Editor**.
3. بزن **New query**.
4. فایل `supabase/SETUP-CHAT-PUSH-ONCE.sql` را باز کن، **کل متنش** را کپی کن،
   در کادر بچسبان.
5. دکمهٔ **Run** را بزن.

**چه چیزی باید ببینی؟** پیام سبز **Success. No rows returned**.

اگر خطای `relation ... does not exist` داد، یعنی اول باید فایل
`supabase/SETUP-COPY-PASTE-ONCE.sql` را اجرا کنی، بعد این یکی.

---

## قدم ۲ — نامه‌رسان را بساز ⏱ ۵ دقیقه

1. منوی چپ: **Edge Functions**.
2. بزن **Deploy a new function** (یا **Create function**).
3. اسمش را دقیقاً بگذار: `chat-push`
4. فایل `supabase/functions/chat-push/index.ts` را باز کن و **کل کدش** را
   داخل کادر آن تابع بچسبان.
5. **Deploy** را بزن.
6. در تنظیمات همین تابع، گزینهٔ **Verify JWT** (یا «Enforce JWT verification»)
   را **خاموش** کن و ذخیره کن.
   👉 دلیلش: این تابع با «کلید» صدا زده می‌شود، نه با حساب کاربر.

**چه چیزی باید ببینی؟** تابع `chat-push` در لیست تو، با وضعیت فعال (Active).

---

## قدم ۳ — یک کلید بساز و پنهانش کن ⏱ ۲ دقیقه

1. یک رشتهٔ تصادفی طولانی بساز (مثلاً ۶۴ حرف/عدد). می‌توانی از هر
   تولیدکنندهٔ رمز در اینترنت استفاده کنی.
2. منوی چپ: **Edge Functions** → **Secrets** (یا Project Settings → Edge Functions).
3. یک Secret جدید بساز: Name = `CHAT_WEBHOOK_SECRET` ، Value = همان رشته.
4. ذخیره کن.

⚠️ این کلید را در چت، در اپ، یا در GitHub نگذار. فقط داخل Supabase می‌ماند.

---

## قدم ۴ — دو زنگ نصب کن ⏱ ۵ دقیقه

منوی چپ: **Database** → **Webhooks** → **Create a new hook**.
**دو بار** این کار را بکن، با این مشخصات:

**زنگ اول**
- Name: `chat-push-queue-insert`
- Table: `public.chat_push_queue`
- Events: فقط **INSERT**
- Method: `POST`
- URL: `https://doagwkssxtxseuavrxnr.supabase.co/functions/v1/chat-push`
- Header ۱: `Content-Type` = `application/json`
- Header ۲: `x-chat-webhook-secret` = همان کلیدی که در قدم ۳ ساختی

**زنگ دوم**
- Name: `chat-push-new-device`
- Table: `public.chat_push_tokens`
- Events: فقط **INSERT**
- بقیهٔ فیلدها **دقیقاً** مثل زنگ اول

**چه چیزی باید ببینی؟** دو Webhook در لیست. اگر روی هرکدام «Test» هست،
می‌توانی بزنی و باید جواب ۲۰۰ بگیری.

---

## قدم ۵ (خوب است، ولی اجباری نیست) — ساعت زنگ‌دار ⏱ ۳ دقیقه

این قدم باعث می‌شود تلاش‌های ناموفق دوباره امتحان شوند و گوشی‌های حذف‌شده
پاک شوند. اگر حوصله نداری، رد شو؛ اعلان بدون این هم می‌آید.

1. **Database** → **Extensions** → `pg_cron` و `pg_net` را روشن کن.
2. در SQL Editor این را اجرا کن (جای `REPLACE_...` همان کلید قدم ۳ را بگذار):

```sql
select cron.schedule(
  'milo-chat-push-maintenance',
  '*/15 * * * *',
  $$
    select net.http_post(
      url := 'https://doagwkssxtxseuavrxnr.supabase.co/functions/v1/chat-push',
      headers := jsonb_build_object(
        'Content-Type', 'application/json',
        'x-chat-webhook-secret', 'REPLACE_WITH_CHAT_WEBHOOK_SECRET'
      ),
      body := jsonb_build_object('type', 'CRON')
    );
  $$
);
```

## قدم ۶ — اپ را روی **گوشی واقعی** نصب کن ⏱ ۲۰ دقیقه انتظار

⚠️ مهم‌ترین نکتهٔ کل این راهنما:

- ❌ نسخه‌ای که در **مرورگر** باز می‌شود → اعلان گوشی **نمی‌دهد** (هیچ‌وقت)
- ❌ برنامهٔ **Expo Go** → اعلان ریموت **ندارد**
- ✅ فقط **APK نصب‌شده** روی گوشی → اعلان دارد

**چطور APK بسازم؟**

1. در GitHub برو به تب **Actions**.
2. از لیست، **Build learner APK** را انتخاب کن.
3. دکمهٔ **Run workflow** → **Run**.
4. حدود ۲۰ دقیقه صبر کن.
5. پایین همان صفحه، در بخش **Artifacts** فایل APK را دانلود کن.
6. فایل را به گوشی بفرست (واتساپ/کابل/درایو) و نصبش کن. گوشی می‌پرسد
   «نصب از منابع ناشناس؟» → اجازه بده.

همین APK را روی **هر دو گوشی** نصب کن (گوشی زبان‌آموز و گوشی مدیر).
برنامهٔ مدیر، همان اپ است؛ فقط با حساب مدیر وارد می‌شوی.

---

## قدم ۷ — اجازهٔ اعلان را بده ⏱ ۱ دقیقه

1. اپ را باز کن و وارد شو.
2. اولین بار یک پنجره می‌پرسد: «اجازهٔ اعلان‌ها؟» → بزن **فعال‌کردن اعلان‌ها**.
3. اگر قبلاً رد کردی: تنظیمات گوشی → برنامه‌ها → Milo → **اعلان‌ها** → روشن کن
   و کانال **«پیام‌ها و درخواست‌های چت»** را هم روشن کن.

روی هر دو گوشی این کار را بکن.

---

## قدم ۸ — امتحان کن ⏱ ۱ دقیقه

1. گوشی زبان‌آموز: یک پیام بفرست.
2. گوشی مدیر را **قفل کن** (یعنی اپ بسته باشد).
3. باید بالای صفحه اعلان بیاید: «پیام تازه از …» با صدا و لرزش.
4. روی اعلان بزن → باید همان گفتگو باز شود.
5. حالا برعکس: مدیر جواب بدهد، گوشی زبان‌آموز قفل باشد.

**چه انتظاری داشته باشیم؟**

| کجای اپ هستی | چه اتفاقی می‌افتد |
|---|---|
| اپ **بسته** یا در پس‌زمینه | اعلان بالای گوشی + صدا + لرزش |
| اپ **باز** ولی در صفحهٔ دیگر | اعلان سیستمی نه؛ یک نوار آرام داخل اپ + عدد روی تب «مکالمه» |
| اپ **باز** و داخل همان گفتگو | هیچ اعلانی (که دوتایی نشود) |

نکتهٔ امنیتی: **متن پیام در اعلان نمی‌آید**؛ فقط اسم فرستنده. این عمدی است
تا پیام خصوصی روی صفحهٔ قفل دیده نشود.

## اگر اعلان نیامد 🔧

| نشانه | معنی | راه‌حل |
|---|---|---|
| SQL خطای «جدول وجود ندارد» داد | صندوق پست ساخته نشده | قدم ۱ (و قبلش SETUP-COPY-PASTE) |
| در Supabase، جدول `chat_push_tokens` **خالی** است | گوشی هیچ‌وقت ثبت نشد | قدم ۶ و ۷ (حتماً APK، نه مرورگر) |
| در `chat_push_queue` ردیف‌های `pending` زیاد است | نامه‌رسان یا زنگ کار نمی‌کند | قدم ۲، ۳، ۴ |
| فقط وقتی اپ باز است اعلان می‌بینی | این همان بنر داخل اپ است، نه پوش | قدم‌های ۱ تا ۴ |
| روی آیفون می‌آید، اندروید نه (یا برعکس) | اجازهٔ اعلان یا کانال خاموش است | قدم ۷ |

برای دیدن وضعیت، در SQL Editor این دو خط را اجرا کن:

```sql
select count(*) as tokens from public.chat_push_tokens;
select status, count(*) from public.chat_push_queue group by 1;
```

- `tokens` باید برای هر گوشی حداقل **۱** باشد.
- `pending` زیاد = گیر در ارسال.
