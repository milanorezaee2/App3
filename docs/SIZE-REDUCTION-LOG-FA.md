### دو تصحیح که در جریان اجرا پیدا شد

**۱. `@expo/vector-icons` از فهرست حذف شد.** این پکیج وابستگی اجباری خودِ `expo` است:

پس از `package.json` ما حذف‌شدنی نیست. و چون هیچ کدی آن را import نمی‌کند، فونت‌هایش هم بسته‌بندی نمی‌شوند. ارجاع `expo-router` به آن فقط داخل یک کامنت است. **ادعای قبلی من در گزارش تحلیل نادرست بود و آنجا تصحیح شد.**

**۲. `react-native-webview` یک peerDependency اختیاری اکسپو است**، پس حذفش واقعاً از باندل خارج می‌شود.

## قدم ۳.۵ (کشف تازه) — حذف ۲۰ فونت مرده ✅

این مورد با اندازه‌گیری واقعی باندل پیدا شد، نه با خواندن کد.

**مشکل:** کد فقط ۷ فونت می‌خواست، ولی باندل ۲۷ فونت داشت.

**علت:** فایل `index.js` پکیج‌های `@expo-google-fonts/*` همهٔ وزن‌ها را با `require()` صدا می‌زند و Metro آن‌ها را حذف نمی‌کند:

```js
export const Inter_100Thin = require('./100Thin/Inter_100Thin.ttf');
export const Inter_200ExtraLight = require('./200ExtraLight/Inter_200ExtraLight.ttf');
// ... ۱۸ فونت Inter و ۹ فونت Vazirmatn
```

**اصلاح در `app/_layout.tsx`:** import از مسیر تکی هر وزن.

```ts
import { Inter_400Regular } from '@expo-google-fonts/inter/400Regular';
```

## نکته‌ای که باید صریح گفته شود

حجم پوشهٔ `.git` از ۷.۸ به ۸.۱ مگابایت **رسیده** و کم نشده. دلیلش این است که آن تصویر ۳.۶ مگابایتی هنوز داخل **تاریخچهٔ گیت** هست. حذف فایل از آخرین کامیت، تاریخچه را پاک نمی‌کند.

یعنی:

- **کلون تازه** هنوز همان ۳.۶ مگابایت را دانلود می‌کند.
- **فایل‌های کاری** از ۱۸ به ۹.۶ مگابایت رسیده‌اند.
- برای کوچک‌کردن `.git` باید تاریخچه بازنویسی شود (`git filter-repo` یا BFG)، که کار جداگانه‌ای است و چون مخزن فقط یک کامیت اولیه دارد، هزینهٔ کمی دارد. **پیشنهاد می‌کنم بعد از تمام‌شدن همهٔ قدم‌ها و در یک عملیات جداگانه انجام شود.**
