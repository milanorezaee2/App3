# دورهٔ Pre-A1 آلمانی، فرانسوی و اسپانیایی

هر زبان ده درس و ۸۰ مثال کوتاه (در مجموع ۳۰ درس و ۲۴۰ مثال)، مکالمه و پرسش خودآموز دارد. سطح‌های بالاتر در نقشه‌اند و هنوز درسی ندارند. این یک دورهٔ شروع از صفر در برنامه است، نه گواهی یا ارزیابی رسمی CEFR؛ برای انتشار نهایی، محتوای هر زبان باید توسط مدرس یا ویراستار همان زبان بازبینی شود. اسپانیایی بر پایهٔ گونهٔ اسپانیا، آلمانی بر پایهٔ گونهٔ آلمان و فرانسوی بر پایهٔ گونهٔ فرانسه طراحی شده‌اند.

رابط مشترک در `components/Starter*.tsx`، درس‌های اصلی در `lib/languages/newCourses.ts` و هشت درس افزوده در `lib/languages/preA1Expansion.ts` قرار دارند. مراحل درس از همان تعریف نه‌مرحله‌ای انگلیسی استفاده می‌کنند. برای عبارت‌های یک‌کلمه‌ای به‌جای چیدن یک دکمهٔ تنها، انتخاب عبارت مناسب از بین گزینه‌ها نمایش داده می‌شود. قالب سه دورهٔ جدید مشترک است؛ صفحه‌های انگلیسی، روسی و ترکی بازنویسی نشده‌اند.

شناسه‌های دو درس نمونه، شش جملهٔ قبلی هر درس و ترتیب گزینه‌های آزمون حفظ شده‌اند. دو جمله به انتهای هر درس نمونه افزوده شده‌اند. با بازخوانی پیشرفت درس‌هایی که قبلاً تکمیل شده‌اند، سازوکار موجود مرور کارت‌های تازه را اضافه می‌کند و زمان‌بندی کارت‌های قبلی را حفظ می‌کند. شناسه‌های منتشرشده باید پایدار بمانند. کلیدهای محلی: `sentence_course_progress_{de,fr,es}_starter_v1` و `{de,fr,es}_starter_lesson_sessions_v1`. پیشرفت‌ها به همگام‌سازی ابری وصل نیستند. داده‌های قدیمی آلمانی که ممکن است در نسخه‌های قدیمی‌تر روی دستگاه مانده باشند خودکار وارد این دوره نمی‌شوند؛ انتقال احتمالی به طراحی و آزمون جداگانه نیاز دارد.

پخش مانند دوره‌های فعلی از `expo-speech` و موتور گفتار دستگاه استفاده می‌کند، نه فایل صدای ضبط‌شده یا گویندهٔ انسانی. کد `lib/starterSpeech.ts` تلاش می‌کند صدای نصب‌شدهٔ هم‌منطقهٔ `de-DE`, `fr-FR`, `es-ES` را انتخاب کند و کیفیت Enhanced را ترجیح دهد. اگر صدای منطقه‌ای نبود، کاربر از احتمال تفاوت لهجه مطلع می‌شود و اگر صدای هیچ گونه‌ای از آن زبان در فهرست نبود پخش انجام نمی‌شود. وقتی فهرست صداها در زمان محدود در دسترس نباشد، درخواست پخش به سیستم واگذار و نبود امکان تأیید لهجه اعلام می‌شود. به‌دلیل رفتار expo-speech اندروید، فیلد language شامل کد کوتاه زبان است و در صورت موجود بودن صدای منطقه‌ای، شناسهٔ آن صدا جداگانه ارسال می‌شود. کیفیت و لهجه به موتور و صدای نصب‌شده بستگی دارند؛ بومی‌بودن یا حضور صدای مشخص روی همهٔ دستگاه‌ها تضمین نمی‌شود. کارگاه تلفظ فقط پخش و تکرار دارد؛ ضبط و ارزیابی خودکار ندارد.

تصاویر اختصاصی آبرنگی انتخاب زبان در `assets/images/language-{de,fr,es}-watercolor.jpg` قرار دارند. دوره‌های جدید به scope پیش‌فرض زبان‌آموز افزوده شده‌اند؛ scope صریح مدیریت همچنان مجزاست. برای پیش‌نمایش شش زبان با ترکی: `EXPO_PUBLIC_LANGUAGE_SCOPE=en,ru,tr,de,fr,es npm run build:web`. خروجی استاتیک برای URLهای سه زبان جدید ساخته می‌شود.

آزمون‌ها: `node scripts/verify-new-language-samples.cjs`، `node scripts/verify-starter-speech.cjs`، `node scripts/verify-app-resume.cjs`، `npm run validate:russian`، `npm run validate:english-lesson-flow` و `npm run typecheck`. شبیه‌سازی API صوت جای شنیدن صدای واقعی و آزمون دستگاه بومی را نمی‌گیرد.
